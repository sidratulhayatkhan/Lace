# Barbados School Connectivity Enhancement

## Project Overview
This project leverages advanced machine learning algorithms to analyze school connectivity data in Barbados. Our aim is to enhance internet connectivity across schools by optimally placing data centers. This interactive web application maps schools' geographical data along with their connectivity speeds and utilizes clustering algorithms to propose strategic locations for data centers.

## Features
- **Interactive Mapping**: Utilize Folium for mapping schools with their internet speed metrics visually on an interactive map.
- **Data Center Optimization**: Apply K-Means clustering to propose the most effective locations for new data centers to maximize connectivity improvements.
- **Ease of Use**: Designed with Streamlit, this web app offers a user-friendly interface for both technical and non-technical users.

## Technologies Used
- **Python**: The primary programming language used.
- **Pandas**: For data manipulation and analysis.
- **Scikit-learn**: For implementing machine learning algorithms.
- **Folium**: Used for generating interactive maps.
- **Streamlit**: To create the web application.
- **Plotly**: For advanced interactive plotting.
- **Requests**: To handle HTTP requests if needed.
